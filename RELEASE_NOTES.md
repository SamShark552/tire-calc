# WheelLab Pro · Release notes

## 2.1.0 · 2026-10-30

- База расширена до 93 профилей; Polo AW/BZ facelift выделен в самостоятельный профиль.
- Исправлен OE-размерный ряд Passat B6 по доступным данным конфигурации 2008 года.
- Перепроверены и уточнены доступные заводские сочетания для Fabia IV, Fabia II/III, Octavia и Superb IV по материалам Škoda/TÜV.
- Superb Combi представлен отдельным кузовным профилем в поколениях 3T, 3V и 3Y; у 3U универсала не было.
- Добавлена Kia Carnival: KV-II, VQ (отдельно 5- и 6-болтовые варианты), YP, KA4 и рестайлинг KA4.
- В BMW 3 Series убраны задние значения staggered-наборов из общего списка как будто это квадратный комплект на все четыре колеса.
- Добавлены схемы кузовов разных типов и семейств: хетчбек, лифтбек, седан, универсал, купе, кабриолет, Gran Turismo и MPV.
- Добавлены импорт/экспорт JSON для переноса гаража между устройствами.
- CSS/JS вынесены в отдельные файлы; подготовлены GitHub Pages/PWA workflow и офлайн-кеширование.
