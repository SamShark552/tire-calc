# WheelLab Pro

Универсальный калькулятор дисков и шин: сравнение размеров, ET, PCD, центрального отверстия, приблизительных зазоров и визуальная примерка по типу кузова.

## Запуск локально

Откройте `index.html` в современном браузере. Для установки PWA и офлайн-кеширования используйте HTTPS (например, GitHub Pages).

## Публикация на GitHub Pages

1. Репозиторий проекта: [SamShark552/tire-calc](https://github.com/SamShark552/tire-calc).
2. Откройте **Settings → Pages** и в разделе **Build and deployment → Source** один раз выберите **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` автоматически публикует сайт при каждом push в `main`; его также можно запустить вручную через **Actions**.
4. После успешного workflow сайт будет доступен по адресу [https://SamShark552.github.io/tire-calc/](https://SamShark552.github.io/tire-calc/).

Проект не использует внешние CDN-зависимости и этап сборки. Service Worker предварительно кеширует интерфейс и его JS/CSS-модули после первого успешного посещения сайта по HTTPS.

## Перенос сохранённых конфигураций

Гараж и пользовательские профили хранятся в `localStorage` конкретного браузера. Сайт откроется с любого устройства, но сохранения автоматически не синхронизируются. Используйте **Экспорт JSON** на старом устройстве и **Импорт JSON** на новом. Облачная синхронизация потребует backend/аккаунтов и в этот статический релиз не входит.

## Точность данных и безопасность подбора

Справочные сочетания собраны по заводским материалам и специализированным каталогам. Даже в рамках одного поколения PCD, ЦО, ET, резьба, размеры шин и допустимая нагрузка могут отличаться по рынку, двигателю и тормозному пакету. Перед покупкой сверяйте VIN, CoC, наклейку давления/размеров и маркировку исходного колеса. Результат калькулятора не является юридическим допуском.

Силуэты автомобилей рисуются процедурно по выбранному семейству и типу кузова (седан, лифтбек, универсал, купе, кабриолет, MPV и т. п.). Это наглядная схема для примерки колёс, а не заводская CAD/3D-модель точной версии кузова.
